# 学习日历与自定义任务设计

**日期：** 2026-10-05
**状态：** TommyWu 已批准
**范围：** StudyClock 本地任务管理、历史统计和 macOS Widget。只处理本地 App Group SwiftData 数据；不增加云同步。

## 目标

1. 用最近 12 个月的学习热力图和连续学习日，补足现有 7 / 15 / 30 天滚动统计。
2. 取消任务数量固定为三项的限制。用户可自行新增、编辑、排序和归档任务，并设置每项每日目标时长。
3. 让中号 Widget 随任务数量采用紧凑布局；任务过多时优先展示正在计时的任务，剩余空间按任务顺序展示。App 始终提供完整任务列表。

## 已拍板方向

- 增加最近 12 个月的学习热力图和连续学习日。
- 取消固定三项上限；任务名称、每日目标时长和顺序可由用户调整，可新增任务。
- 新安装保留现有三项作为可编辑起始任务；已有安装保留原任务 ID、配置和计时事件。
- 中号 Widget 随任务数动态排布；小号 Widget 保持现状。

## 建议默认口径（待 TommyWu 审阅）

- 归档而非物理删除：归档任务退出计时和 Widget 操作列表，但仍计入历史、日统计和热力图；可恢复。
- 活动任务须先暂停才能归档；空任务列表显示新增入口。
- 中号空间不足时优先当前任务，再按排序放入可读范围；本阶段不增加大号 Widget。
- 修改每日目标后，历史目标完成率继续按当前目标估算并保留提示；不记录目标变更历史。
- 重命名保留 task ID 和计时事件；历史显示使用当前名称，不复制历史名称快照。
- 不引入登录、网络同步、番茄钟、任务颜色或任务数量硬上限。

## 页面与交互

### 任务管理

- 主仪表盘增加“管理任务”入口，打开独立任务列表。
- 任务列表支持新增、编辑名称、调整每日目标、排序和归档。
- 新增任务必须有非空名称；每日目标沿用现有非负秒数语义，可设为 0（未设目标）。
- 若任务正在计时，先暂停后才能归档；不得让已归档任务继续在后台累计。
- 归档后仍可从历史和热力图日期明细中识别该任务；如需恢复，可在任务管理中取消归档。
- 全部任务归档时显示明确空状态和新增入口；历史数据不变。

### 学习日历

- 在现有统计界面中提供“统计 / 学习日历”切换，避免在主仪表盘再增加独立导航层级。
- 热力图范围从今天向前 12 个本地日历月的对应日期起，包含今天；今天显示截至当前的部分日累计。
- 每个本地日按所有任务的实际累计时长着色，不按目标完成率着色；颜色等级固定为：无投入、(0, 1800) 秒、[1800, 3600) 秒、[3600, 7200) 秒、≥7200 秒。目标变更不改写历史热力图强度。
- 点选有记录或无记录的日期，显示日期、总学习时长和按任务分项时长；归档任务保留在分项中。
- 连续学习日以本地日累计时长大于 0 作为“有学习”的定义，不依赖每日目标。显示当前连续天数和可见 12 个月内最长连续天数；当前连续天数可以向窗口之前延伸。若今天尚无投入，则当前连续天数以昨天为止的连续记录计算。
- 日边界通过 `Calendar` 计算；跨午夜事件按本地日切片，DST 日不按固定 86,400 秒计算。

## 数据与架构

- `TimerActionRecord` 仍是计时事实来源；热力图复用 `TimerReducer` / `TimerSnapshot` 的区间计算，不写入逐日计时副本。
- `StudyTaskRecord` 保留稳定 UUID；扩展归档状态并提供新增、更新、排序、归档/恢复操作。归档状态升级必须兼容既有 App Group store。
- 查询需区分活动任务和包含归档项的历史任务：计时器、Widget 仅操作活动任务；每日历史总计、热力图总时长和分项包含归档任务。
- `TimerViewModel` 为视图提供活动任务管理和日历汇总值；SwiftUI 不直接读写 SwiftData 模型。
- 中号 Widget 使用同一共享 store 和既有 App Intent；按“当前计时任务优先，其余 sortOrder”生成动态任务列表。小号 Widget、reset/start/pause 语义、Timeline 重载和跨进程通知不变。
- 统计页和热力图不得将整年聚合挂到每秒 `TimelineView` 更新闭包中；打开页面或共享快照变更时重新聚合，当前日显示累计值。

## 验收

1. 新安装出现三项可编辑起始任务；可以新增第四项及更多任务，调整名称、目标、顺序；现有用户升级后原任务 ID 与事件均不变。
2. 归档活动任务前必须暂停；归档任务不再可启动，但它的原有历史时长仍计入日总计、统计及热力图分项；恢复后可再次计时。
3. 任务改名不拆分计时记录；每日目标为 0 时显示未设目标；修改目标不回写历史目标数据。
4. 热力图准确覆盖 12 个月本地日期；今天的运行中计时可计入当前日；跨午夜和 DST 结果正确；零学习日不计入 streak。
5. 中号 Widget 按当前计时任务优先且按排序填充可读内容；所有 Widget 动作仅针对未归档任务；小号布局保持原行为。
6. 现有 7 / 15 / 30 天统计、reset 行为、历史数据迁移和 App Group 共享行为不回归。

## 验证重点

- SwiftData 旧 store 增加归档状态后的兼容打开与既有记录保留。
- 活动任务归档拒绝路径、归档后 reducer 历史聚合、恢复后可操作路径。
- 任务顺序变化对仪表盘、统计卡片和 Widget 的一致性。
- 12 个月日期窗口、空历史、连续日边界、跨午夜、DST、当前活动区间及归档任务的日分项。
- 实际中号 Widget 在不同任务数量下的可读布局；小号 Widget 不变。

## 非目标

- 不提供任务永久删除、历史计时重新归属或历史名称快照。
- 不保存每日目标历史；不将旧日期的目标完成率伪装成当时真实设定。
- 不增加大号 Widget、任务颜色或按标签筛选。
- 不提交、推送或改写 Git 历史；未经单独要求不对外发布。
